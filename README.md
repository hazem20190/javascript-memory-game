# 🎮 Memory Blocks Game

A fun and interactive Memory Card Game built with **HTML, CSS, and JavaScript**.

Flip the cards, find matching pairs, and challenge your memory!

## ✨ Features

- 🎲 Randomized card order for a new experience every game.
- 🃏 Interactive card-flipping animations.
- 🧠 Matching logic to find identical pairs.
- ❌ Wrong attempts counter.
- 👤 Personalized player name.
- 💗 A special dedication to my beautiful family: Asmaa, Karem, Aylin, and Tia.
- 📱 Responsive and user-friendly design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎯 How to Play

1. Click **Start Game** to begin.
2. Enter your name.
3. Flip two cards to reveal their images.
4. Find matching pairs to complete the game.
5. Try to match all pairs with as few wrong attempts as possible!
